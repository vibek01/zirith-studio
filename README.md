# Zirith Studio ✦

A premium, high-converting B2B agency website built for **Zirith Studio**. We specialize in high-end SaaS motion design, product explainers, and VSLs that engineer behavior and drive conversions.

![Zirith Studio](public/zirithLogo.jpeg)

## Live Preview
[https://zirith-studio.vercel.app](https://zirith-studio.vercel.app)

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **3D Graphics:** React Three Fiber & Drei

## Key Features
- **Premium Aesthetic:** Warm brownish-beige palettes with sophisticated typography ("Apple meets high-end architectural firm").
- **Interactive 3D Hero:** Custom React Three Fiber morphing orb that reacts to cursor movement and clicks.
- **Dynamic Bento Grid:** Beautifully animated scroll-reveal cards outlining agency services and social proof.
- **Single-Step Booking:** Streamlined, frictionless modal form to capture high-intent leads instantly.
- **Engaging Value Props:** Interactive, elegant accordion layouts for philosophy and strategy highlights.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/vibek01/zirith-studio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
