# Zirith Studio Project Structure

This file provides a tree-like folder structure representation of the Zirith Studio project along with a brief one-line description of each file's primary purpose.

```
ZIRITH CLAUDE/
├── .eslintrc.json           # ESLint configuration file defining rules for code style and quality.
├── .gitignore               # List of files and folders intentionally ignored by Git version control.
├── README.md                # Standard project overview, setup guides, and description of features.
├── next-env.d.ts            # TypeScript compiler directive file automatically generated by Next.js.
├── next.config.js           # Configuration file defining Next.js build options, redirects, and environment parameters.
├── package-lock.json        # Automatically generated registry of installed node packages and their exact versions.
├── package.json             # Root configuration file declaring project metadata, run scripts, and npm dependencies.
├── postcss.config.js        # PostCSS build configuration, primarily integrating Autoprefixer and Tailwind CSS.
├── tailwind.config.js       # Custom Tailwind CSS theme settings specifying design system colors, font families, and plugins.
├── test-math.js             # Local scratch mathematical model script testing custom Y-axis SVG coordinate mapping.
├── tsconfig.json            # Configuration options for the TypeScript compiler and module resolution.
├── public/                  # Directory containing static public assets.
│   └── zirithLogo.jpeg      # Zirith Studio branding logo image.
└── src/                     # Core React application source code directory.
    ├── app/                 # Next.js App Router containing pages, layouts, and global styles.
    │   ├── globals.css      # Main stylesheet containing global CSS rules, tailwind directives, and color variables.
    │   ├── layout.tsx       # Root layout component rendering custom preloader, smooth scrolling, and metadata.
    │   └── page.tsx         # Main landing page assembling UI sections, interactive components, and 3D scenes.
    ├── components/          # Collection of reusable UI blocks, sections, and 3D scene elements.
    │   ├── sections/        # High-level UI sections comprising the landing page.
    │   │   ├── BentoGrid.tsx      # Performance metrics showcase showcasing before/after conversions with animated SVG charts.
    │   │   ├── Footer.tsx         # Site footer with social links, office locations, navigation, and newsletter signups.
    │   │   ├── Hero.tsx           # Engaging hero landing block featuring the primary value proposition and R3F canvas.
    │   │   ├── Investment.tsx     # Budgeting and project tiers section containing interactive selection slides.
    │   │   ├── Navbar.tsx         # Responsive glassmorphism navigation header with magnetic interactions.
    │   │   ├── Services.tsx       # Core services outline highlighting motion design, SaaS explainer, and VSL offerings.
    │   │   ├── TrustMarquee.tsx   # Continuous horizontal scrolling marquee displaying trust-building client logos.
    │   │   └── ValueProp.tsx      # Detailed breakdown of proprietary methodology and behavioral pacing value pillars.
    │   ├── three/           # React Three Fiber (R3F) 3D scene elements.
    │   │   ├── CrystalGeo.tsx     # Custom 3D crystal geometry rendering refractive and interactive glass materials.
    │   │   ├── HeroOrb.tsx        # High-performance 3D glowing particle orb designed for above-the-fold visual impact.
    │   │   └── PrismScene.tsx     # Three.js Canvas container supplying background lighting and post-processing filters.
    │   └── ui/              # Atom/UI level utility elements and generic layout containers.
    │       ├── AnimatedCounter.tsx   # Typography helper animating counting numbers when visible in viewport.
    │       ├── AnimatedLineChart.tsx # Scalable vector graphics (SVG) chart component tracing data growth curves.
    │       ├── BookingModal.tsx      # Step-by-step custom scheduling form modal enabling users to book consultation calls.
    │       ├── FloatingCTA.tsx       # Mouse-tracking floating interactive bubble prompting users to take action.
    │       ├── LenisProvider.tsx     # Core React wrapper enabling smooth kinetic scrolling across the site using Lenis.
    │       ├── MagneticButton.tsx    # Premium interaction component applying spring-dampened magnetic cursor pull physics.
    │       ├── Preloader.tsx         # Premium initialization loader screen displaying progress percentages and typographic intro.
    │       ├── ScrollReveal.tsx      # Viewport trigger wrapping elements to smoothly transition them into view.
    │       └── TextReveal.tsx        # Dynamic typography component separating sentences into animated word entries.
    ├── hooks/               # Custom React hooks encapsulating stateful utility functions.
    │   ├── useInView.ts     # Wrapper hook for Intersection Observer tracking node visibility within viewport.
    │   └── useMagnetic.ts   # Mouse listener hook calculating Spring-dampened displacement coordinates.
    └── lib/                 # Shared data modules, configs, and application utility helpers.
        ├── colors.ts        # Central repository specifying hex values, gradients, and tailwind color mapping constants.
        └── constants.ts     # Configuration records including navigation links, client logos, services data, and options.
```
